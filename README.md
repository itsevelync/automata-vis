# Automata Visualizer

An interactive tool for designing, visualizing, and simulating automata, including DFAs, NFAs, PDAs, and Turing machines, using state diagrams.

Supports importing and exporting state diagrams as LaTeX with TikZ.

## Tools

- Add, move, and delete states.
- Connect states with directed transitions.
- Label nodes and transitions.
- Mark states initial, accepting, or both.
- Test your automaton with an input.
- Export a `tikzpicture` of your diagram.

## Built With

This website was developed using [Vite](https://vite.dev/) and [React](https://react.dev/), with icons from [React Icons](https://react-icons.github.io/react-icons/) and math typesetting from [KaTeX](https://katex.org/).

The educational materials that informed this project are from [Dr. Joseph Jaeger](https://faculty.cc.gatech.edu/~josephjaeger/) and Georgia Tech's CS 4510 course.
